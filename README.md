# roiland-rfl
Roiland Football League sim engine. Layout: `rfl/` (engine, game, season, build_page, weekly), `data/` (league.json, compressed state `rfl_state_2042.z64`), `out/season_template.html` (stripped copy of the published 2042 Season page).

Restore: `python3 -c "import sys; sys.path.insert(0,'.'); from rfl.engine import *; save(read_project_state('data/rfl_state_2042.z64'),'data/state_2042.json')"`, then `python3 rfl/weekly.py N`.
State: 2043 season open at week 0 (`data/state_2043.json`, compressed `data/rfl_state_2043.z64`); the 2043 schedule (360 games, Dan's 67 primetime/pinned placements kept, zero rule violations — seed 12 of `rfl/fill_anneal.py`, audited by `rfl/audit_schedule.py`) and broadcast slots are installed. Current year is `data/current_year.txt`; state paths come from `engine.STATE`/`engine.Z64`. Season page: RFL 2043 Season (https://claude.ai/artifact/LWYWAYh7HUx2AgQrEBVfUe). Week 3 played (27 Oct 2026); League Office (`rfl/league_office.py`, `rfl/build_league_office.py`) runs between weeks: ballot, Dan decides on the page, `apply N file`, then `weekly.py N+1`. Next: Dan decides week 3 ballot, then `python3 rfl/weekly.py 4`.
